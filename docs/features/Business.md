### 1. Introduce
BacNaoDay is a simple website to show Vietnamese family relations and remind what is its relatives.

### 2. Business
- Login/logout
    - username/password
- Create relation pages(each page could be one family relation), naming it.
- Create person node inside relation page.
- User could pick one person node and mark as your. Select other person node to get what is your relation and relative name.

### 3. Business analyze rules:
- Base on business, analyze and break it into multiple small features for easy implement single one instead of chain with others. 
- Each feature should be simple with short description for easy understand what need to do. Do not mention about tech implement in this part.
- Save its result into `docs\features\analyze.md`
- For each feature, analyze tech requirement, implement steps documentation and save it into `docs\features\v{number}-{feature-name}.md`
Example: `docs\features\v1-simple-login.md`
